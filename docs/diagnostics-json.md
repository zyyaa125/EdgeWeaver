# 本地结构化诊断

运行 `moon run cmd/main` 后，最后一行是 UTF-8 JSON 诊断快照。`LocalDiagnostics::to_json(role=...)` 也可供节点和控制面启动器调用。时间为 Unix 秒；尚未发生的连接与重试时间、尚无错误类别以 JSON `null` 表示。

输出包含节点 ID 和角色、生命周期与健康、连接状态和最近成功连接时间、下次重试时间、待处理与丢弃事件数、同步游标和失败次数、最近错误**类别**、协商能力、离线策略状态以及执行记录各状态计数。执行记录 `InProgress` 计入 `uncertain_executions`，需要人工核查，不能自动重复执行。

该投影只读取上述字段。原始事件日志、错误消息、命令动作及运行器输出不进入 JSON；因此诊断 JSON 不能代替审计日志。节点 ID 仍是操作员可见标识，应按部署环境控制日志访问。当前只有同步失败类别 `sync`，尚无跨进程聚合或持久化诊断服务。
